Fix Instant Shots 1.0 for OpenWarThink

Every shot of every weapon now flies its whole way to the target.

In the original MechWarrior 2: Mercenaries a projectile slot keeps the point where its last shot
stopped. The next shot through that slot tests its path from there, so when the target stood still,
every second shot (a laser, a PPC, a cannon round, a missile) hit at once, without flying.
This mod makes every shot start its path where it leaves the weapon.

Install: unzip into the Mods folder next to MW2Mercs.exe, so that Mods/fix-instant-shots/mod.json
exists. In the game: Options -> Mods, RELOAD, make sure it is ON, ACCEPT.

Damage, range, speed and everything else stay as in the game; only the instant hits are gone.
In a network game every player needs this mod (the game says so if someone lacks it).
