# Security policy

OpenWarThink includes a network mode (MercNet) that opens a UDP port while you host or join a
game. If you find a security problem in it, or anywhere else in the project, please report it
privately: open the repository's **Security** tab and choose **Report a vulnerability**.

Please do not report security problems in public issues. Fixes go into the `main` branch; there
are no separately supported releases yet.
